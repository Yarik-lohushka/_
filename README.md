# SUPER PRIZE — Chaos / Deadpan Edition

Полностью переработанный адаптивный шуточный сайт для GitHub Pages.

## Файлы
- `index.html` — структура сайта
- `style.css` — дизайн, анимации, мобильная адаптация
- `script.js` — каталог, колесо, испытание, случайные события, секретная кнопка
- `assets/` — 17 реалистичных изображений призов и визуальные материалы

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите всё содержимое папки `super-prize-chaos` в корень репозитория GitHub.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку `main`, папку `/ (root)`, нажмите Save.
5. Откройте опубликованную GitHub Pages ссылку.

Важно: это шуточный интерактивный сайт. Он не проводит реальный розыгрыш, не собирает личные данные и не принимает оплату.
