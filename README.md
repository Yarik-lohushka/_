# SUPER PRIZE — ULTIMATE EDITION

Полностью статический шуточный сайт для GitHub Pages.

## Структура архива

В корне архива лежат:
- `index.html` — разметка и разделы сайта;
- `style.css` — дизайн, адаптивная сетка, состояния и анимации;
- `data.js` — каталог объектов;
- `app.js` — поиск, фильтры, избранное, колесо, испытание, модальные окна и интерактивность;
- `favicon.svg` — иконка вкладки;
- `assets/` — локальные изображения.

**Важно:** загружайте именно содержимое архива в корень репозитория. Не помещайте всё в дополнительную вложенную папку.

## Публикация

1. Распакуйте ZIP.
2. Откройте репозиторий GitHub.
3. Загрузите `index.html`, `style.css`, `data.js`, `app.js`, `favicon.svg` и папку `assets` в корень репозитория.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch.
6. Выберите `main` и `/ (root)`, нажмите Save.
7. Подождите завершения публикации и откройте адрес Pages.

Если сайт уже опубликован, замените старые файлы новыми и дождитесь нового deployment. При проверке после загрузки обновите страницу без кэша.

## Проверки и совместимость

- Все изображения подключаются локально из `assets/`; внешние сервисы для картинок не нужны.
- Google Fonts используются как необязательное улучшение: при отсутствии сети остаются системные шрифты.
- Учитывается системная настройка уменьшения анимации.
- Звук не включается автоматически.
- Поиск, сортировка, фильтры, избранное, колесо и испытание работают на стороне браузера.
- Избранное и пользовательские данные не отправляются на сервер.
- Нет платёжных форм, логинов, сбора личных данных или настоящего розыгрыша.

SUPER PRIZE — сатирический интерактивный проект. Все призы виртуальные и не выдаются в реальности.
