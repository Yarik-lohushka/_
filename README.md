# SUPER PRIZE — абсурдный шуточный портал

Готовый статический сайт для GitHub Pages. Не является настоящим розыгрышем, не собирает личные данные и не принимает платежи.

## Содержимое
- `index.html` — страницы и интерфейс
- `style.css` — адаптивный дизайн, анимации
- `script.js` — случайные призы, 7 испытаний, пасхалки и финал
- `images/` — 17 реалистичных студийных изображений призов

## Публикация на GitHub Pages
1. Распакуй архив.
2. Создай репозиторий на GitHub.
3. Загрузи **всё содержимое** папки `super-prize-site` в корень репозитория.
4. Открой Settings → Pages.
5. В Build and deployment выбери Deploy from a branch.
6. Выбери ветку `main` и папку `/ (root)`, нажми Save.
7. Через минуту открой ссылку, показанную в разделе Pages.

Важно: не переименовывай папку `images` и не перемещай картинки из неё.
