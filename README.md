# Линейка Prize — шуточный сайт

Статический сайт для GitHub Pages. Не является настоящим розыгрышем и не собирает личные данные.

## Файлы
- `index.html` — разметка
- `style.css` — оформление и адаптация под телефон
- `script.js` — анимация колеса и шуточный финал
- `images/` — изображения

## Как опубликовать
1. Создай публичный репозиторий на GitHub.
2. Загрузи **всё содержимое** этой папки, сохранив папку `images`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main`, папку `/ (root)` и нажми Save.
6. Подожди минуту и открой адрес, который появится в разделе Pages.

Изменить название и тексты можно прямо в `index.html`.
